## 2. 路线决策：移植机制，不用 sidecar

| 维度 | A. 移植到 Python（推荐） | B. Rust 服务当 sidecar（端口 18234） |
|------|------------------------|-----------------------------------|
| 与价值系统耦合 | episode 天然带 RPE/reward/weights 快照，网络可直接按价值强化 | 服务看不到这些信号，只能当外挂问答机 |
| LLM 端点坑 | stepfun reasoning_content 恒空的坑已在 llm_client.py 解决（CoT 清理） | Rust client.rs 需重踩一遍 |
| 人格一致性 | 一套 DNA：awareness/self/value 种子和生命本体同源 | 双进程两套种子 = 精神分裂 |
| 工作量 | 分期可控（见 §4） | 接口快，但语义适配层迟早要重写 |
| 已验证质量 | 需要移植后重新验证（有基准可测） | 直接享受 99.4% |

选 A。蓝本的 LongMemEval 测试脚本（bench/longmemeval_test.py）改造成 Python 版验收工具。

## 3. 目标架构

```
┌─ 存储层（不变）────────────────────────────┐
│ episodes.jsonl 追加式，全量原始经历永不删改   │  ← 哲学：原始经历是"你是谁"
├─ 记忆网络层（新增 memory/network/）──────────┤
│ Node: content/summary/embedding/level       │
│       factual(来源定)/D_node/状态机/out_links│
│ Edge: weight/reliability/co_activated       │
│       /semantic_description(建边理由)        │
│ mechanism.tick: 衰减+Hebbian+状态迁移        │
├─ 检索层（重构 retrieval.py）────────────────┤
│ 向量种子(ACTIVE+SILENT池) → 扩散激活 → 合并   │
│ agent 查询改写 3 角度 → CP2 校验 → expand    │
├─ 写副作用 ─────────────────────────────────┤
│ RecallEventNode（默认不进检索池）             │
├─ 后台（对接 PHASE 15）─────────────────────┤
│ 空闲三阶段 + 梦境重编译 + 可靠性探针          │
└────────────────────────────────────────────┘
```

关键设计取舍（全部来自蓝本已验证机制）：

1. **factual 由信号来源决定，不由 LLM 判断**（types.rs:130-148）。GenesisX 映射：新闻中心/工具输出等外部观察 → factual 不衰减；自身行动经历 → experiential 正常衰减。零 LLM 成本。
2. **CognitiveLevel 是属性不是骨架**（signal/event/concept/self/awareness 五档）——只给建边 LLM 提供线索，扩散不过滤 level，拓扑全靠权重。
3. **节点状态机 + 迟滞**：ACTIVE(D≥0.5)→SILENT→ARCHIVED→DEEP_SLEEP，降级跌破 0.48、恢复达 0.5 即回（防振荡）；只有 ACTIVE+SILENT 进检索池，天然控成本。
4. **分档指数衰减**：D = D×exp(-γΔt)，按 level 分档半衰期（signal≈5min/event≈1h/concept≈1天/self≈1周），awareness 恒 1.0。参数集中可调（对应 ParamGenes）。
5. **Hebbian 双路强化**：tick 批量 Δw = η·damp·D_src·D_tgt − δ（agency=self 时 damp=0.5 防自激活正反馈）+ 检索命中即时强化。被一起激活的边变强，无人走的边自然消退。
6. **边永不删除只冻结**：低于 W_MIN=0.1 冻结为 0.01 保留结构，可恢复可审计。
7. **抽象即建边副产物**：LLM 发现共同模式就建 Concept 节点（D=0.4 候选态），无晋升门控，用得多留下、不用衰减淘汰——替代传统 rollup。
8. **LLM 建边 + embedding top-8 候选预筛 + 幻觉 ID 过滤**；边带 reliability_score，检索时 effective_weight = weight × reliability。
9. **CP1/CP2 语义校验点**：建边后 LLM 查边理由与内容是否矛盾（矛盾丢弃）；回忆后 LLM 查激活集是否回答了查询（失败 expand 重试一次）。校验调用失败时静默放行，不阻塞主循环。
10. **两阶段快照**：批量更新先快照全部 D/weight 再统一计算最后原子写回，消除遍历顺序依赖。

## 4. 分期实施计划

### Phase 1：零 LLM 纯机制（网络层 + 检索换血）

- 新建 `memory/network/` 包：`node.py`（Node+状态机）、`edges.py`（Edge+冻结）、`mechanism.py`（衰减+Hebbian+两阶段快照）。familiarity.py 的 AssociativeNetwork 平行保留，稳定后退役。
- 检索重构：向量种子召回（ACTIVE+SILENT 池）替换标签预筛 → 扩散激活（branch=3, max_hops=4, 每跳×0.7）→ 普鲁斯特加成接真实 mood/stress（顺手杀 bug #4）。
- agent 查询改写：3 角度改写合并（蓝本 bench 的召回功臣，纯检索侧技巧）。改写失败降级单查询。
- 数据迁移：现有 5000+ episodes 冷启动导入——batch 模式（零 LLM：embedding 相似 top-5 建 similarity 边），高 |delta| 节点后续靠 Phase 2 LLM 建边逐步充实。
- 网络快照持久化：每生命 `artifacts/persistent/{A|B|C}/network.json`（节点 5k 规模 JSON 足够，不需要 sled）。

验收：单测（状态机迟滞/衰减分档/Hebbian 收敛/边冻结）+ 三生命检索人工抽查不退化。

### Phase 2：LLM 机制（建边 + 校验 + 回忆事件）

- intake 理解：LLM 产出 summary/cognitive_level/importance（接 organ_llm_session 现有链路，走 flash 档）。
- LLM 建边：embedding top-8 候选 + 建边决策（type/target/weight/reason）+ 幻觉 ID 过滤 + CP1 矛盾校验。
- 抽象涌现：建边时发现共同模式 → Concept 节点 D=0.4。
- CP2 回忆校验 + expand 重试。
- RecallEventNode 完整版：LLM 判定 meaningful + 生成 3-5 triggers + 向量查重(0.85)合并；**默认排除出检索池**。

成本：每 tick 新增约 2-3 次 LLM 调用（理解+建边可合并为一次，CP 按需）。三生命轮班同时只有一个活跃，可接受。stepfun 推理延迟风险：校验超时静默放行。

验收：CP1/CP2 拦截率日志、建边幻觉率、RecallEventNode 查重合并正确性。

### Phase 3：后台生命化

- 空闲三阶段调度：空闲 30 步 → 强化弱连接/打捞高入度归档节点/Jaccard 去重合并；300 步 → 自由联想。
- 梦境重编译对接 PHASE 15 DreamConsolidator：现有 schema/skill 抽取保留，新增"低强度 concept 摘要重写"。
- 可靠性探针：滑动窗口 100 条回复 claim 级一致率，<0.85 黄牌 <0.70 红牌。

### Phase 4：基准验证

- LongMemEval-S 移植跑分（蓝本 bench 脚本改造），对比 99.4% 基线。
- 网络结构分析复用：小世界 σ、幂律 alpha、模块度（bench/network_analysis.py 思路）。

## 5. 哲学对照检查

| 用户哲学 | 本设计的落地 |
|---|---|
| 不加提示词，改机制 | 检索能力来自网络拓扑 + Hebbian 强化，不往 mind 提示词里塞"你有记忆网络" |
| 不硬约束 | 回忆安全网 30 次上限只防卡死不设认知预算；抽象无晋升门控，靠使用/衰减自然淘汰 |
| 让它自己翻 | 记忆网络对生命可grep/read（对应蓝本 recall 工具集，Phase 2+ 评估是否暴露为 limb 工具） |
| 原始经历都保留 | episodes.jsonl 永不删改（pruning.py 已删）；网络是索引与联想层，不是替代 |
| schema 是归纳不是替代 | schema→concept 节点入网；skill 保持独立库（它是可执行序列，不是回忆） |
